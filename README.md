# 轮叙四箴 · 赣南师范大学 GIS 数字孪生滚动叙事

> 以校训「博达毅卓」为轴，一次滚动，滚过赣师四年：南门大石碑的三百米、蓝海操场的十四天、一教大堂的背书大军、抛向 2029 年天空的学士帽。

校园以 GIS 方法数字孪生：校内数据库 109 栋建筑的真实轮廓层数楼名，经坐标锚定程序化拉伸成三维楼群；卫星影像底座按六点标定链对齐场景；楼名以同学 ArcGIS 作业成图为唯一依据转录纠错。每一帧画面与文案，均由多智能体集群生成、评审、迭代，人类只负责提出想念。

## 试玩

- **在线**：仓库开启 GitHub Pages 后，直接访问仓库首页地址即可（如 `https://<用户名>.github.io/lunxu-sizhen/`）
- **本地**：下载 `index.html` 双击打开（推荐 Chrome/Edge，断网可运行）

## 操作

向下滚动 = 时间前进；右下角「博 / 达 / 毅 / 卓」可跳章；「一键放映」自动放映全程（约 2 分钟，滚轮可中断）；滚到底部观看演职员表。

## 技术

- `GNNU数据库.mdb` 规范建筑面 → 自研 shapefile 解析（+4 变体布局）→ 蓝海主环质心锚定 + 8 分区非刚性锚定 → three.js 程序化楼群（窗格 / 层线 / 描边 / 屋顶设备盒）
- Google Earth 2025-11 卫星底座：town 六点标定链（像素→真实米）与场景零残差闭合，运行时 canvas 降饱和羽化合成
- 75 块楼名楼牌 CanvasTexture sprite，按相机距离淡出；道路三级分级 + 中央虚线 + 斑马线；湖面顶点波动
- 多智能体集群（智谱 GLM）：导演编排、视觉评审循环、代码实现
